# dsh-context-snapshot-bar

<img src="docs/assets/libersum99.svg" alt="LiberSum99" width="144" height="24"> <a href="https://github.com/topics/dsh-plugin"><img src="docs/assets/dsh-plugin.svg" alt="dsh-plugin" width="100" height="24"></a>

DeepSeek Harness が現在保持しているコンテキストを可視化します。実行時スナップショット、メッセージの流れ、直近の圧縮で残された内容を確認できます。

## プラグインの機能

- **コンテキスト・スナップショット**：最新のルール、生成元、記録時刻を表示し、有効・クリア済み・置換済みを区別します。
- **会話の流れ**：ユーザーメッセージ、アシスタントのツール呼び出しと結果をターン単位で表示。直近の圧縮要約と、置き換えられたメッセージを比較できます。
- **表示場所**：入力欄の上にある入口から右サイドバーを開き、タブで2つの表示を切り替えます。

プラグインは記録済みの Session イベントを読み取ります。会話ログへの書き込みや、DSH の AgentLoop・圧縮方針の変更は行いません。モデルによる補助要約は任意で利用でき、モデルルートを設定しなくても元の記録を確認できます。

## 対応バージョン

| 項目 | バージョン |
| --- | --- |
| インストール・動作確認の記録がある DSH | **`0.1.5-rc.2`（Host + Web）** |
| 現在のプラグイン | `0.2.0` |
| Session / Projection の依存関係の宣言範囲 | `>=0.1.5-rc.2 <0.2.0-0` |
| Node.js | `^22.19.0 \|\| >=24.0.0` |

依存関係の宣言範囲は、動作確認済みの範囲とは異なります。他の DSH バージョンは未検証です。対象の配布物と確認内容は[互換性の記録](docs/compatibility.md)を参照してください。

## クイックスタート

DSH を事前にインストールしてください。プラグインのビルドには pnpm が必要です。以下はプラグインのソースディレクトリで実行します。`.tgz` パッケージがある場合、最初の3つの手順は省略できます。

```sh
pnpm install
pnpm run build
pnpm run pack
dsh plugin --profile web add ./artifacts/dsh-context-snapshot-bar-0.2.0.tgz
dsh --profile web --dump-config
```

出力に `dsh-context-snapshot-bar` の設定レイヤーがあることを確認し、**対象の Web サービスを再起動**します。

```sh
dsh --profile web
```

すでに起動している場合は、既存のプロセスを停止してから実行してください。起動時に表示された新しい URL を開き、会話の入力欄上部にあるスナップショットの入口を選択すると、サイドバーが開きます。

独自の Web profile を使用する場合は、`web` をその名前に置き換えてください。この手順はローカルパッケージを使うもので、npm での公開を前提としていません。

## 補足

- **リアルタイム表示の範囲**：記録済みイベントに応じて更新されます。トークン単位のストリーミング表示ではありません。最新のスナップショットが現在のモデルコンテキストから外れている場合もあります。
- **補助要約のリクエスト**：モデルルートを設定すると、カードが保持するセクションのテキストを送信する追加リクエストが発生します。無効化や表示上限の設定は[設定・開発ガイド](docs/guide.md)を参照してください。
- **長い会話とアニメーション**：省略された内容の件数を表示します。現在のバージョンは圧縮前後の比較に対応していますが、古いメッセージ群を縮めるアニメーションは未実装です。
- **アンインストール**：次のコマンドを実行し、サービスを再起動してください。会話データは保持されます。

```sh
dsh plugin --profile web remove dsh-context-snapshot-bar
```
